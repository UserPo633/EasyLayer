What this demo actually does

This is an EasyLayer web simulator with a guided interface. It calls the same MCP booking tools and persistent drafts as the assistant integration candidate. It is not a native Alexa+ session.

Microphone input uses your browser’s speech service, when available. Contact details are entered only on the separate review page. This local demo uses one demo identity; it is not a multi-user sign-in service.
